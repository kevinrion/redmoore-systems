# redmoore-systems

Redmoore Systems is a fictional company built around IoT and telemetry across multiple sectors.

The product vision is an operational platform for collecting, managing, and observing device/sensor data — with the engineering materials emphasizing reliability, observability, and production-grade safety rather than a flashy consumer app.

Technically, the project is planned as a Laravel + Inertia.js + React (TypeScript) monolith on PostgreSQL/Eloquent: server-driven UI without a separate REST/GraphQL layer, Tailwind + shadcn/ui for the frontend, and Pest/Playwright plus PHPStan/ESLint as quality gates. The “golden rules” focus on zero client trust, API Resources instead of raw models, N+1 prevention, queue offloading for external work, and real telemetry/APM (Laravel Pulse, Sentry/Datadog-class tools) — fitting for a systems company whose own product story is telemetry.

Visually, the brand is industrial and restrained: deep crimson (#7D0308 / #96181E), warm secondary gold (#E6A54B), dark olive text on soft off-white panels, Oxygen as the primary typeface, and a geometric mark that reads as infrastructure/hardware rather than consumer SaaS. Altogether, planning points to a serious B2B IoT telemetry product with a clean, operational UI and a conservative engineering culture.
